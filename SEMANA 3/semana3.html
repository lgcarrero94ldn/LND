Implantación de Aplicaciones Web (IAW)

1º Trimestre: Crear páginas web autónomas, correctamente estructuradas, semánticas y accesibles.

Comprender cómo llega un documento HTML al navegador y crear una primera página. HTML5.

Es fundamental dominar las etiquetas básicas como las de encabezado (del h1 al h6), las etiquetas de párrafo, los comentarios ocultos para el usuario y el uso de atributos que modifican el comportamiento de los elementos.

Práctica 3: Servicios Informáticos de ASIR

Presentación de soluciones tecnológicas y servicios profesionales para empresas y sistemas en red.

Nuestros Servicios Profesionales

1. Administración y Despliegue de Servidores

Gestionamos la infraestructura de servidores de tu empresa para garantizar la máxima disponibilidad y rendimiento.

Tecnologías principales utilizadas:

  • Sistemas Operativos Windows (7,8,10,11) / Linux (Ubuntu Server, Debian)
  • Servidores Windows Server y Active Directory
  • Virtualización de sistemas con Oracle VirtualBox
  • Servicios web y de bases de datos (SQL)

2. Diseño y Configuración de Redes

Planificamos e implementamos arquitecturas de red seguras, eficientes y adaptadas a las necesidades del negocio.

Fases del despliegue de infraestructura:

  1. Estudio y análisis del mapa físico de la instalación.
  2. Configuración de routers, switches avanzados y VLANs.
  3. Despliegue y optimización de redes inalámbricas (Wi-Fi profesional).
  4. Monitorización continua del tráfico y balanceo de carga.

3. Auditoría y Seguridad Perimetral

Protegemos los activos más valiosos de tu empresa frente a accesos no autorizados y amenazas cibernéticas.

Soluciones de ciberseguridad implantadas:

  • Instalación y reglas avanzadas de Cortafuegos (Firewalls / pfSense)
  • Configuración de conexiones remotas seguras mediante redes VPN
  • Sistemas automáticos de copias de seguridad (Backups) encriptadas

4. Soporte Técnico y Mantenimiento

Ofrecemos una resolución ágil de incidencias para asegurar que la actividad de tu empresa nunca se detenga.

Modalidades de soporte técnico:

  1. Monitorización preventiva de sistemas y alertas críticas.
  2. Asistencia remota inmediata mediante conexiones encriptadas.
  3. Intervenciones técnicas presenciales programadas.
