1. Administración de Sistemas Operativos

1.1. Servidores Linux

Guías esenciales para la configuración y endurecimiento de servidores basados en distribuciones Linux empresariales.

Comandos fundamentales de administración:

  • Gestión de servicios del sistema.
  • journalctl - Consulta y análisis de logs del sistema.
  • Gestión de permisos y propietarios de archivos.

1.2. Servidores Windows

Documentación técnica para la implementación de servicios en entornos corporativos Microsoft.

Roles principales a configurar:

  • Active Directory Domain Services (AD DS)
  • Servidor DHCP y DNS interno

2. Infraestructura de Redes y Seguridad

2.1. Enrutamiento y Conmutación

Manuales para la configuración de dispositivos de red en la capa de acceso y distribución.

Tareas de configuración prioritarias:

  1. Segmentación de tráfico mediante VLANs.
  2. Configuración de protocolos de enrutamiento dinámico (OSPF).
  3. Implementación de listas de control de acceso (ACLs).

2.2. Seguridad Perimetral

Directrices para proteger la red interna frente a amenazas externas.

  • Políticas estrictas en el Firewall empresarial.
  • Configuración de túneles VPN IPsec para teletrabajo seguro.
