Implantación de Aplicaciones Web (IAW)

1º Trimestre: Crear páginas web autónomas, correctamente estructuradas, semánticas y accesibles.

Comprender cómo llega un documento HTML al navegador y crear una primera página. HTML5.

Es fundamental dominar las etiquetas básicas como las de encabezado (del h1 al h6), las etiquetas de párrafo, los comentarios ocultos para el usuario y el uso de atributos que modifican el comportamiento de los elementos.
